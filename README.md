# Resolvedor de EDOs

Um projeto desenvolvido para a disciplina de Equações Diferenciais Ordinárias na graduação em Eng.Elétrica da Universidade Federal do Piauí. O intuito deste projeto é o de resolver EDOs complexas usando algoritmos baseados nos métodos estudados em classe.
Desenvolvido por:
João Victor Carvalho Rocha (splantapot)

## Lista de siglas (arquivos):

- EDO: Equação Diferencial Ordinária
- 1O: Primeira Ordem
- 2O: Segunda Ordem
- MCFI: Método dos Coeficientes Indeterminados (No geral, para EDOs2O)
